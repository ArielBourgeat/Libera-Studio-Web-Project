# LÍBERA STUDIO
> **Hecho para Durar.**

A conceptual MVP website for LÍBERA STUDIO, a clothing brand developed around a natural, minimal, contemporary, and lifestyle-oriented visual identity.

---

## Overview

This project was created as a personal design and web development practice project. It is not an official website for the brand and was not developed as a final deliverable. The goal was to experiment with visual storytelling, interactive elements, motion, typography, layouts, and the integration of branding into a digital experience.

The website is designed as a visual-first experience rather than a traditional e-commerce store. The main concept is to introduce the brand through movement, photography, video, and interactive product elements before leading the user toward the catalog.

The visual direction combines a strong black-and-white base with natural and warm tones inspired by clothing, materials, photography, and lifestyle aesthetics.

* **Main Concept:** *Hecho para Durar. / Made to last.*

---

## Project Goals

The project explores:
* Brand identity translated into a digital interface.
* Editorial-inspired web design.
* Visual storytelling through video and photography.
* Interactive product presentation.
* Scroll-based navigation.
* Minimal typography and large visual elements.
* Hover interactions and micro-interactions.
* Responsive web layout.
* HTML, CSS, and JavaScript implementation.
* The relationship between Figma prototypes and the final website.

---

## Design

The website was designed in Figma before being developed in HTML, CSS, and JavaScript.

The design direction focuses on:
* Minimalism
* Editorial layouts
* Large typography
* High contrast
* Natural colors
* Product-focused imagery
* Full-width visual sections
* Interactive stickers
* Motion and video
* Clean navigation

The intention is to make the website feel closer to a fashion campaign or digital lookbook than a conventional online store.

## Website Structure

```text
/

├── index.html

├── about.html

├── Shop.html

├── Styles.css

└── Script.js

* index.html: The main landing page and primary visual experience.

* about.html: The conceptual About page, intended to communicate the identity and philosophy behind LÍBERA STUDIO.

* Shop.html: The product/catalog section where users can explore clothing and accessories.

* Styles.css: Contains the main visual system including layout, typography, colors, spacing, buttons, navigation, image positioning, hover states, responsive behavior, and section styling.

* Script.js: Handles interactive functionality, including dynamic elements and interactions used throughout the experience.

## Homepage Experience

The homepage follows a defined visual flow:

1. **Intro / Hero**
   * Visual introduction using video and large-scale visual content.
   * Features LÍBERA STUDIO branding, intro video, minimal navigation, a `SCROLL` indicator, and a downward arrow.
   * Top navigation using small uppercase white typography (`ABOUT`, `CATÁLOGO`, `INTERACTIVO`).
   * Introductory motion inspired by [Space Type Generator — Flash](https://spacetypegenerator.com/flash).

2. **Floating Images**
   * Visual gallery composed of floating product and lifestyle images against a near-black background with white text.
   * Designed to generate curiosity, introduce clothing visually, break traditional grids, and build anticipation.

3. **Behind The Scenes**
   * Showcases a Behind The Scenes (BTS) video/reel, supporting text, and a `VER CATÁLOGO` CTA button leading to the Shop page.

4. **Interactive Sticker Section**
   * Features the `FEEL FREE. USE FREEDOM.` section (`Use © LÍBERA.`).
   * Product PNGs (tote bag, hat, hoodie, t-shirt) function as interactive stickers distributed across the screen to encourage discovery.

5. **Footer**
   * Includes designed text/image elements, horizontal navigation, brand visuals, large copyright text, and link interactions within a minimalist framework.

## Interaction Design

* **Navigation:** Small uppercase links to maintain a clean, editorial appearance.
* **Hover States:** Important buttons use burgundy as a subtle hover accent.
* **Interactive Products:** Product graphics in the sticker section act as interactive visual objects.
* **Scroll Experience:** Structured around gradually revealing the brand as the user scrolls.
